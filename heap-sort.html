排序穩定性不穩定

堆積排序會先用 O(n) 時間建立最大堆積，再進行 n 次取出堆頂操作，每次調整堆積最多花 O(log n)，因此整體時間為 O(n log n)。排序演算法本身直接在原陣列內交換，額外空間為 O(1)；此互動頁為了同時顯示堆積樹與排序結果，會另外保留堆積資料，整體畫面資料使用 O(n) 空間。

堆積排序與氣泡排序的時間複雜度比較

情況堆積排序氣泡排序（有提前停止）
最佳O(n log n)O(n)
平均O(n log n)O(n²)
最差O(n log n)O(n²)

資料量增加時，堆積排序的運算成長較慢，較適合大量資料且需要穩定的 O(n log n) 效能；氣泡排序寫法直觀，適合小型資料或教學示範。氣泡排序的最佳 O(n) 是指每輪檢查後若沒有交換便提前結束；若未加入這項最佳化，即使資料已排序，最佳時間仍是 O(n²)。

核心程式

JavaScript 實作 
function heapSort(array) {
  const n = array.length;

  function siftDown(root, heapSize) {
    let current = root;
    while (true) {
      const left = current * 2 + 1;
      const right = left + 1;
      let largest = current;

      if (left < heapSize && array[left] > array[largest]) largest = left;
      if (right < heapSize && array[right] > array[largest]) largest = right;
      if (largest === current) break;

      [array[current], array[largest]] = [array[largest], array[current]];
      current = largest;
    }
  }

  // 建立最大堆積
  for (let i = Math.floor(n / 2) - 1; i >= 0; i--) {
    siftDown(i, n);
  }

  // 將最大值依序移到陣列尾端
  for (let end = n - 1; end > 0; end--) {
    [array[0], array[end]] = [array[end], array[0]];
    siftDown(0, end);
  }
  return array;
}
