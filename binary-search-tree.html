BINARY SEARCH TREE / 01

二元搜尋樹

第一個數字成為根節點。接下來的數字逐一比較：較小就往左，較大就往右，直到找到空位。

輸入數列

最多 80 個整數

可用逗號、頓號或空格分隔。重複的數字會累計在同一節點。

逐步檢視

尚未建立樹

最近一次比較

輸入數列後，這裡會顯示插入路徑。

樹狀圖

0 個節點

輸入一組數字並建立二元搜尋樹。圖形會依照插入順序排列。

樹的走訪結果

分別依前序（根、左、右）、中序（左、根、右）、後序（左、右、根）輸出。

前序建立樹後即可輸出。
中序建立樹後即可輸出。
後序建立樹後即可輸出。

每個節點的左子樹都較小，右子樹都較大。
